# Checklist HTML (referencia)

## Documento
- [ ] `<!DOCTYPE html>` en la primera línea.
- [ ] `<html lang="…">` con el idioma correcto.
- [ ] `<meta charset="UTF-8">`.
- [ ] `<meta name="viewport" content="width=device-width, initial-scale=1.0">`.
- [ ] `<title>` descriptivo (no "Document").

## Estructura
- [ ] `<header>`, `<nav>`, `<main>`, `<footer>` donde corresponda.
- [ ] Uso de `<section>` / `<article>` según el contenido.
- [ ] Un único `<h1>`; niveles de encabezado sin saltos.
- [ ] Listas reales con `<ul>` / `<ol>` / `<li>`, no guiones de texto.

## Contenido y multimedia
- [ ] Imágenes con `alt` descriptivo (`alt=""` si es decorativa).
- [ ] Enlaces con texto significativo (no "clic aquí").
- [ ] Formularios: cada `<input>` con su `<label>` asociado (`for`/`id`).
- [ ] Tablas con `<caption>`, `<thead>` y `<th>`.

## Calidad
- [ ] Todas las etiquetas cerradas y correctamente anidadas.
- [ ] Atributos escritos en minúsculas y entre comillas.
- [ ] Indentación consistente (2 espacios).
- [ ] Sin rutas absolutas al sistema de archivos.
